A 4 KB Python chess engine: 0x88 board, negamax with alpha-beta and quiescence search, a transposition table, killer moves and iterative deepening on a fixed 90,000-node budget. No clock, no randomness: the same position always gives the same move. Practice trial Elo 1545 (4 wins, 1 draw, 1 loss against the house gauntlet's first six engines).

## Run it

```sh
MAKEFUN_ENV_URL=http://localhost:8080 python3 main.py
```
